# Justin8 Dev-tap

## How do I install these formulae?

`brew install justin8/dev-tap/<formula>`

Or `brew tap justin8/dev-tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "justin8/dev-tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
